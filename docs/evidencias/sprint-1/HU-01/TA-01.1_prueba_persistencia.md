- **Responsable:** Kevin Balseca
- **Fecha de la prueba:** 22 oct 2026, 00:02 a 00:05 (-05:00)
- **Entorno:** Windows 11, Docker 29.9.2, Docker Compose v5.6.0
- **Archivo probado:** `moodle-lab/docker-compose.yml` (commit `6da1f65`)
- **Criterio de aceptación:** Moodle accesible en localhost y persistente entre reinicios.

Todos los comandos se ejecutaron desde la raíz del repositorio. Para abreviar, `$C` equivale a:

```
docker compose -f moodle-lab/docker-compose.yml --env-file .env
```

No se muestran contraseñas. Dentro de los contenedores, `sqlcmd` lee `$MSSQL_SA_PASSWORD` del entorno.

## 3. Datos de prueba

Categoría creada con Moosh, la CLI de Moodle que trae la imagen:

```
> $C exec -T moodle sh -c 'cd /var/www/html && moosh -n category-create "Prueba persistencia"'

```

Base creada con `sqlcmd` dentro del contenedor de SQL Server:

```
> $C exec -T sqlserver sh -c '/opt/mssql-tools18/bin/sqlcmd -S localhost -U sa -P "$MSSQL_SA_PASSWORD" -C -b -Q "CREATE DATABASE PruebaPersistencia;"'
(sin errores, código de salida 0)
```
