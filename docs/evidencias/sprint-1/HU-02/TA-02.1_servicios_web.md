## 1. Configuración por CLI

Todo se hizo por CLI, sin pasos manuales en la interfaz. El script está versionado en `moodle-lab/scripts/configurar_servicios_web.php` y es idempotente.

```
> docker exec edumonitor-moodle-1 php /var/www/html/admin/cli/cfg.php --name=enablewebservices --set=1
> docker exec edumonitor-moodle-1 php /var/www/html/admin/cli/cfg.php --name=webserviceprotocols --set=rest
> docker cp moodle-lab/scripts/configurar_servicios_web.php edumonitor-moodle-1:/tmp/
> docker exec edumonitor-moodle-1 php /tmp/configurar_servicios_web.php

  enablewebservices=1
  webserviceprotocols=rest
  rol creado
  rol con 10 capacidades
  usuario creado
  rol asignado al usuario
  servicio creado
  servicio con 8 funciones
  usuario autorizado en el servicio
  TOKEN_NUEVO=••••9f10   (se mostró una sola vez a Kevin y se pegó en .env)
```

Capacidades del rol `edumonitor_lectura`, todas de lectura:
- `webservice/rest:use`
- `moodle/course:view`, `moodle/course:viewparticipants`
- `moodle/user:viewdetails`, `moodle/site:accessallgroups`
- `gradereport/user:view`, `moodle/grade:viewall`
- `mod/assign:view`, `mod/assign:viewgrades`
- `report/progress:view`

Ninguna permite escribir, calificar ni ver correos.

Segunda ejecución del script (idempotencia):

```
rol con 10 capacidades
rol asignado al usuario
servicio con 8 funciones
Token existente: ••••9f10 (no se regenera)
```
