# TA-05.6 · 10 notas comparadas entre Moodle y EduMonitor

Fecha: 29 oct 2026. Curso: AGIL-4B «Metodologías Ágiles (lab)» (id de Moodle 2), con los datos de `moodle-lab/scripts/cargar_datos_laboratorio.php`.

## Cómo se obtuvo

1. Prueba automatizada `SincronizacionMoodleRealTests.Sincroniza_AGIL_4B_y_10_notas_coinciden_con_Moodle`: levanta la API, inicia sesión como `doc01`, llama a `POST /api/cursos/{id}/sync` contra el Moodle de laboratorio real y compara las notas guardadas en EduMonitorDB con las que devuelve Moodle. La base de la prueba es SQLite en memoria; el Moodle es el real.
2. Comprobación independiente: las mismas 10 notas consultadas directamente en la base de Moodle (`mdl_grade_grades` y `mdl_assign_submission`), sin pasar por el cliente de EduMonitor.

```powershell
dotnet test backend/EduMonitor.sln --filter "FullyQualifiedName~SincronizacionMoodleReal" --logger "console;verbosity=detailed"
```

La prueba se omite si no hay `.env` con `Moodle__Token` (por ejemplo, en CI).
